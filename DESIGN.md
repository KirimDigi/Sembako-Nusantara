## 4. TARGET PENGGUNA

### 👥 Segmen Utama

#### Segmen 1 — Diaspora Indonesia di Jepang
- **Siapa:** Pekerja, mahasiswa, keluarga Indonesia yang tinggal di Jepang
- **Kebutuhan:** Produk sembako Indonesia, bumbu masak, makanan instan favorit
- **Pain point:** Susah cari produk Indonesia, harga mahal di toko fisik
- **Frekuensi belanja:** 2-4x per bulan

#### Segmen 2 — Komunitas Muslim di Jepang
- **Siapa:** Warga Muslim dari berbagai negara yang tinggal di Jepang
- **Kebutuhan:** Produk halal yang terjamin, bumbu halal, makanan halal
- **Pain point:** Sulit memastikan kehalalan produk di Jepang
- **Frekuensi belanja:** 1-3x per bulan

#### Segmen 3 — Pecinta Kuliner Asia/Indonesia
- **Siapa:** Warga Jepang atau WNA yang suka masakan Indonesia
- **Kebutuhan:** Bumbu otentik, produk unik dari Indonesia
- **Pain point:** Tidak tahu cara masak Indonesia, tidak tahu beli di mana
- **Frekuensi belanja:** 1-2x per bulan

#### Segmen 4 — Restoran & Usaha F&B
- **Siapa:** Restoran Indonesia, katering halal, bisnis makanan di Jepang
- **Kebutuhan:** Pembelian grosir, stok rutin, harga kompetitif
- **Pain point:** Supplier tidak reliable, minimum order terlalu besar
- **Frekuensi belanja:** Weekly/bulanan dalam jumlah besar

## 10. PENGIRIMAN & LOGISTIK

### 🚚 Layanan Pengiriman

| Layanan | Estimasi | Keterangan |
|---|---|---|
| **Yamato Transport** | 1-3 hari | Standar, terpercaya |
| **Sagawa Express** | 1-3 hari | Alternatif standar |
| **Japan Post** | 3-7 hari | Ekonomis |
| **Cool Delivery** | 1-2 hari | Khusus frozen/dingin |

### 📦 Kebijakan Pengiriman
- **Gratis ongkir:** Pembelian min. ¥7.000
- **Kirim ke:** Seluruh 47 prefektur Jepang
- **Packaging:** Aman, rapi, anti bocor
- **Tracking:** Real-time via nomor resi
- **Waktu proses:** 1-2 hari kerja setelah pembayaran dikonfirmasi

### 🧊 Pengiriman Khusus Frozen
- Menggunakan cool box + dry ice
- Tersedia cool delivery (tambah biaya)
- Estimasi 1-2 hari (tidak bisa weekend)

## 11. TECH STACK & ARSITEKTUR

### 🏗️ Rekomendasi Tech Stack

#### Frontend (Tampilan Website)
```
Framework  : Next.js 14 (React)
Styling    : Tailwind CSS
UI Library : Shadcn/UI
Language   : TypeScript
State      : Zustand / Redux Toolkit
```

#### Backend (Server & Logika)
```
Opsi A (Cepat)  : Supabase (PostgreSQL + Auth + Storage)
Opsi B (Besar)  : Golang + Gin Framework + PostgreSQL
Database        : PostgreSQL
Cache           : Redis
Queue           : RabbitMQ (untuk notifikasi)
```

#### Infrastructure
```
Hosting        : Vercel (frontend) + Railway/Render (backend)
Database       : Supabase / Neon PostgreSQL
Storage        : Cloudinary (gambar produk)
CDN            : Cloudflare
Domain         : .com / .jp
SSL            : Otomatis (Let's Encrypt)
```

#### Integrasi Pihak Ketiga
```
Payment        : DOKU + Stripe + PAY.JP
Shipping       : Yamato API + Japan Post API
Notifikasi     : SendGrid (email) + Firebase (push)
Analytics      : Google Analytics 4
LINE           : LINE Messaging API (Official Account)
WhatsApp       : WhatsApp Business API
```

### 🗄️ Struktur Database (Utama)

```sql
-- Tabel Utama
users           -- Data pelanggan

categories      -- Kategori produk
orders          -- Pesanan

payments        -- Data pembayaran
shipping        -- Data pengiriman
reviews         -- Review produk
vouchers        -- Kupon & diskon
points          -- Poin reward
referrals       -- Program referral
```
